# Benchless AI

Benchless AI is an Expo and React Native app for recovery-aware training check-ins.

## Run locally

```sh
npm install
npm start
```

Use Expo Go to scan the QR code, or run `npm run android` / `npm run ios` with a configured native development environment.

The onboarding flow currently covers a welcome screen, sport selection, and a pain-area check-in. Expo Router is kept as the app foundation.
